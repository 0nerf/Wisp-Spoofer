## How to use

Open the app. Search for any game you want and click. The game you selected runs RPC on discord if you want to farm a streak or complete quests then click enable Process Spoofing.
But Discord is working on new detection systems. Which may get your account banned from quests you may lose access to quests for 14-days. This app is not tested with Discord's new detection systems. use at your own risk.
If you are farming game streaks you wont get banned but you may get banned from quests. If you enable Process Spoofing, game you selected runs as an .exe process in task manager you won't see that .exe on your screen. Its working on Discord and everyone will see your selected game and it also work with Xbox.

**Note:** If you want to farm streaks or completing quests, you need to enable Process Spoofing.

**Warning:** Discord has recently introduced countermeasures against quest farming. Using this app to complete quests is at your own risk.
